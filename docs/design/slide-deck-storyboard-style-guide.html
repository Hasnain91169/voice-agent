Voice Agent storyboard and style guide

Use the existing dark console language: mint signal color, quiet panels, waveform texture, and precise measured claims. Avoid implying unfinished adapters or telephony are shipped.

Storyboard

1. Hook

Hero banner: real-time, local-first, measured. Lead with p50 719ms and barge-in 219-328ms, then name the known p95 weakness.

2. Audio path

Show RxPump ownership, FrameChannel, VAD, ASR, LangGraph, TTS, playback. Mention framework boundary.

3. Turn taking

Explain the 1000ms budget and why 450ms endpointing shipped.

4. Interruption

Barge-in is cancellation plus memory discipline: commit what was heard.

5. Evaluation

Split deterministic checks, model judge, text mode, and audio mode.

6. Measurement honesty

Close with the failures the harness caught and the unresolved judge issue.
